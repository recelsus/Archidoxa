The tree should show entries from the selected content section. In this template, the only configured section is `sample`, so the section view and the global view are easy to compare.

The `All` navigation item is the explicit global mode. It can show every visible section and a month-based tree. If more sections are added later, those sections should appear from configuration rather than from hardcoded links.

This separation keeps local reading focused while preserving a site-wide browsing mode.
