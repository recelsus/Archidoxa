This sample article provides enough body text to evaluate the relationship between the main article, the left navigation tree, and the side-note panel.

The layout should feel dense enough for repeated reference use. Large decorative gaps make scanning harder, while overly compressed text makes long pages tiring. This page sits between those extremes.

The article column should remain the main reading surface. Supporting panels should be useful when needed, but they should not compete with the body text.
